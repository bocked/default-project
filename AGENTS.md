## Git ish tartibi (MAJBURIY)
- Har bir vazifa/ozgarish tugagach, qo'lda so'ramasdan AVTOMATIK:
  1. `git add .`
  2. mos xabar bilan `git commit`
  3. `git push origin main`
- Commit xabarlari ingliz tilida, kichik/aniq (masalan: `fix: ...`, `feat: ...`, `chore: ...`).
- Vazifa ichida bir nechta mustaqil o'zgarish bo'lsa, ularni mantiqiy guruhlarga ajratib commit qilish mumkin, lekin tugagach hammasi push bo'lishi shart.
